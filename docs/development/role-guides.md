# Пользовательские руководства в приложении

Кнопка «Памятка» открывает документацию текущей роли с оглавлением, поиском,
пошаговыми инструкциями, таблицами, примерами и иллюстрациями. Содержание для
контрагента составлено отдельно: общие внутренние главы к нему не добавляются.
Поиск выполняется только по текущему руководству.

## Источник и обновление

Рабочий контент — [roleGuides.ts](../../web/src/shared/content/roleGuides.ts),
типы блоков и поиск — [roleGuideTypes.ts](../../web/src/shared/content/roleGuideTypes.ts).
Исходные DOCX и архивные памятки не определяют поведение приложения.

Перед изменением сверяйте действия с `backend/app/domain/permissions.py`,
domain policies, актуальными services и видимыми UI labels. Роль, область данных,
дополнительные права и статус записи описываются отдельно. Скрытая кнопка не
должна превращаться в обещанную возможность по тексту памятки.

Для каждой существующей роли требуется собственная запись. У сотрудников
должны оставаться главы сравнения руководителя проекта, ведущего экономиста
и экономиста, а также главы об иерархии. Названия ролей пишутся полностью.
Контрагенту доступны только
инструкции о его собственных действиях и иллюстрации его интерфейса.
В каждой главе нужен хотя бы один скриншот по её теме. Для нескольких глав
подходит один и тот же скриншот, если на нём видно описанное действие.
Используйте маркированные учебные данные.
Ссылку для обращения к контактному лицу берите из того же источника, что и
ссылку MAX в подвале приложения.

## Иллюстрации и проверка интерфейса

```powershell
npm --prefix web run docs:screenshots
```

Команда использует установленные frontend dependencies, Chromium Playwright
и Python с зависимостями IAM для рендера формы входа. По умолчанию используется
Python из `.venv`, если он есть, либо `python` из PATH. Путь можно задать в `GUIDE_PYTHON`.
При отсутствии браузера установите его через `npm --prefix web exec playwright install chromium`.
Запускается временный локальный Vite на `127.0.0.1:4197`, после проверки он
останавливается. Скрипт использует компоненты приложения и текущую форму входа
IAM. Браузер перехватывает запросы чтения и подставляет учебные ответы из
[role_guide_fixture_responses.mjs](../../scripts/role_guide_fixture_responses.mjs).
Остальные запросы к API, запросы записи и внешние URL блокируются.

Список PNG берётся из глав руководств. Файлы обновляются в `web/public/guides/`.
Desktop/mobile контрольные снимки и `verification.json` сохраняются в
игнорируемом `artifacts/role-guides/`. В снимках таблиц часть столбцов скрыта
штатной настройкой для читаемости. Для скриншотов диалогов убираются углы
затемнения и тень. Вводные иллюстрации показывают поиск и найденные главы.
В руководстве снимки сохраняют пропорции и уменьшаются по доступной ширине
и высоте. По нажатию открывается оригинал. Широкие таблицы прокручиваются
горизонтально.

Для проверки оформления с уже сохранёнными PNG запустите
`npm --prefix web run docs:screenshots -- --check-only`.

## Проверки

- `npm --prefix web run lint`
- `npm --prefix web run test:unit`
- `npm --prefix web run build`
- `npm --prefix web run docs:screenshots`
- `python scripts/check_docs.py`
- `python scripts/check_mojibake.py`

Unit tests проверяют все роли, уникальность глав, наличие иллюстраций, поиск и
изоляцию контрагента. Browser checks открывают все главы и декодируют все
иллюстрации. Отдельные проверки покрывают desktop/mobile, ширину страницы,
переход к главе с клавиатуры и поиск по своей роли. На широких экранах оглавление
занимает всю высоту области чтения и прокручивается отдельно от главы.

## Импорт старого DOCX для сравнения

```powershell
python scripts/generate_role_guides_from_docx.py path/to/approved-guides.docx --debug-output artifacts/docx/role-guides.json
python scripts/inspect_docx.py path/to/approved-guides.docx --output artifacts/docx/structure-sample.json
```

Нужен `python-docx`. По умолчанию импорт создаёт черновик
`artifacts/docx/roleGuides.ts`, не перезаписывая рабочее руководство. Черновик
старого формата не предназначен для прямого подключения к приложению: переносите
только сверенное содержание в текущую схему с chapter ID и разделением ролей.
