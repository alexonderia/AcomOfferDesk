# Отчёты

Датированные результаты и наблюдения, а не инструкции по текущему поведению приложения. Имя: `YYYY-MM-DD-topic.ext`; дата соответствует описанному прогону или наблюдению. Парные форматы имеют одинаковое основание имени.

- [QA-отчёты](qa/README.md): результаты тестирования и материалы приёмки.
- [Изменения репозитория](maintenance/2026-11-10-repository-cleanup.md): перенос правил, документации и истории.
- [Завершённые планы и старые чеклисты](../archive/README.md) находятся в архиве.

Новый отчёт должен содержать дату, commit/ветку или описание рабочего дерева, окружение, выполненные проверки, артефакты и ограничения. Старый успешный прогон не подтверждает новую версию.
