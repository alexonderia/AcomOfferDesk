## Проверка в браузере

1. Нормативный PDF: две страницы, переход к следующей, canvas содержит изображение страницы. Desktop и экран 390×844.
2. DOCX: реальная библиотека browser bundle, текст, таблица, sandbox, отсутствие активных ссылок.
3. XLSX: первый/второй листы, отображение HTML-подобного значения как текста.
4. PNG: изображение успешно декодировано.
5. Неподдерживаемый DOC: предварительный запрос содержимого не выполняется; кнопка скачивания отдаёт файл под исходным именем.
6. Имитированный отказ в чтении 403: понятное сообщение без попытки отобразить документ.
7. Один существующий нормативный PDF прочитан из локального приложения и успешно открыт. Анонимное скачивание этого файла возвращает 401.
8. Выбранный локальный PDF в форме создания заявки открыт до отправки без загрузки на сервер.

Для стабильных сценариев форматов метаданные нормативов и бинарные ответы подменены только в тестовом браузере. Существующие файлы/статусы/пользователи не изменялись, новые записи не создавались. Штатные запросы авторизации и выдачи WebSocket-билетов не считаются изменениями бизнес-данных.

Все перечисленные браузерные проверки прошли на финальной сборке. Запросов изменения бизнес-данных — 0. Результаты — `runtime.json`; изображения — `pdf-desktop.png`, `pdf-mobile.png`, `docx.png`, `xlsx.png` в каталоге артефактов.
