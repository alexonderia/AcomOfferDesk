# Архив

Исторические материалы сохраняют контекст решений и результатов. Они не задают текущее поведение; действующие документы перечислены в [каталоге](../README.md).
Старые статусы `in_progress`, данные тестовых аккаунтов и результаты прогонов не переносятся в текущую задачу автоматически.

| Каталог | Содержимое |
|---|---|
| `iam/` | Проектные DOCX IAM v1.0–v1.4 от августа 2026, отчёт IAM/RBAC и исходная схема БД |
| `qa/` | Старые backlog, baseline-чеклисты, журналы CSV и завершённый план исправлений |
| `audits/` | Датированные аудиты прежнего состояния кода |
| `incidents/` | Разборы и действия по историческим инцидентам |
| `staff-import/` | Версии комплектов ТЗ/данных импорта; v1 и v2 отличаются от v3 |
| `role-guides/` | Выгрузки исходных памяток и предыдущий генератор |
| `backups/` | Исторический снимок основной БД и прежнего identity provider |
| [Trellis](trellis/README.md) | Локальный проверенный snapshot удалённого workflow |
| [Локальные материалы](local/README.md) | Игнорируемый архив бывшего `.tmp/`, без публикации credentials и логов |

Имя исторического документа начинается с даты, указанной в исходнике; если исходная дата неизвестна, используется дата архивации. Для импортов сохранены их исходные версии. Содержимое бинарных документов и данных при перемещении не менялось.

Дата 10.11.2026 у backlog corrections и baseline-чеклистов без исходной даты означает архивацию, а не новый прогон тестов.

## Резервная копия 11.05.2026

[Описание исходного комплекта](backups/2026-05-11-migration-bundle/README.md) относится к старому окружению. Его исходные пути VPS и команды оставлены как история; локальный комплект теперь расположен в `docs/archive/backups/2026-05-11-migration-bundle/`.
Это снимок данных, не шаблон для нового deploy. Не восстанавливайте его в текущую БД без отдельного поручения. Исходные checksums сохранены. Текстовые JSON/SQL возвращены к исходным окончаниям строк LF после проверки совпадения с этими SHA-256; `.gitattributes` защищает их от повторной конвертации Windows. Бинарный dump не изменялся.

Наличие более поздней версии не означает, что данные уже импортированы или согласованы для текущей БД. ZIP-копии удалены после побайтной проверки совпадения с распакованными файлами.
