# Предпросмотр документов и вложений

## Где доступен

- **Нормативные документы:** кнопка «Предпросмотр» рядом со скачиванием. При создании заявки также можно просмотреть выбранный нормативный документ.
- **Заявки и КП:** нажатие на имя прикреплённого файла открывает окно просмотра. Это работает в карточке заявки, таблице/карточках КП и рабочем пространстве КП, включая доступную контрагенту карточку.
- **Чат:** нажатие на вложение сообщения открывает предпросмотр.
- **До сохранения:** выбранные файлы в формах создания/редактирования заявки, ручного КП и сообщения можно открыть до отправки. Для этого локальный файл не загружается на сервер.

В окне остаются кнопки «Скачать» и закрытия. Просмотр не удаляет вложение, не отправляет форму и не открывает карточку строки под диалогом.

## Форматы и ограничения

| Формат | Отображение |
| --- | --- |
| PDF | Постраничное отображение, предыдущая/следующая страница, вписывание по высоте окна с ограничением по ширине, увеличение/уменьшение; работает на телефоне без встроенного PDF-плагина |
| PNG, JPG/JPEG | Изображение с подстройкой размера |
| DOCX | Текст, встроенные изображения и таблицы в упрощённом оформлении |
| XLSX | Выбор листа и значения ячеек; формулы не пересчитываются, используются сохранённые значения |
| TXT, CSV, JSON, XML, Markdown, LOG | Безопасный текст, без исполнения HTML; поддерживаются UTF-8, UTF-16 с BOM и Windows-1251 |
| GIF, WEBP, BMP, AVIF | Изображение, если такой исторический файл доступен для чтения |
| Другие форматы, в том числе DOC/XLS, HTML и SVG | Сообщение о недоступности предпросмотра и отдельное скачивание |

Предпросмотр ограничен 20 МБ. Для Office перед разбором проверяются структура ZIP, количество записей (до 2000) и заявленный распакованный объём (до 32 МБ). XLSX показывает первые 500 строк и 50 столбцов выбранного листа, текст — начало до 512 КиБ; при усечении выводится пояснение. Парольные/повреждённые документы предлагается скачать. Исходные оформление DOCX/XLSX, формулы, печатный вид и полный объём сохраняются в оригинале, который доступен по кнопке скачивания.

Правила загрузки не расширены: новые файлы по-прежнему ограничены действующим списком форматов и 5 МБ на файл.

## Масштаб и размер окна

Окно просмотра занимает доступную высоту экрана. Страница PDF и изображение при открытии вписываются целиком в область под заголовком и кнопками; пропорции сохраняются, узкий экран дополнительно ограничивает ширину. Размер пересчитывается при изменении окна.

Кнопки «Увеличить»/«Уменьшить» меняют масштаб от 25% до 400% с шагом 25%. Для PDF/изображений 100% означает вписывание в окно, а не исходный размер в пикселях. При увеличении появляется прокрутка внутри области просмотра; кнопка «По высоте окна» возвращает к 100%. Увеличение не загружает файл повторно и не разбирает PDF заново. При открытии другого файла масштаб сбрасывается.

В DOCX масштаб меняет размер содержимого sandbox-iframe, в XLSX — таблицы, в текстовых форматах — текста. Длинные документы прокручиваются внутри окна. Для больших увеличений PDF размер bitmap ограничен 8 млн пикселей, чтобы не расходовать неограниченную память на canvas.

## Доступ и обработка

Удалённое содержимое читается через существующий авторизованный `GET /api/v1/files/{id}/download`, с теми же проверками разрешений и области доступа. Для нормативов сохраняется отдельная проверка `normative_files.read`, для бизнес-вложений — доступ к связанным заявке/КП/сообщению. Новый публичный файловый endpoint не добавлен.

Клиент принимает только ссылки на файлы своего приложения, использует обычное обновление авторизации `apiFetch`, запрашивает содержимое с `cache: no-store` и ограничивает объём ответа, включая поток без Content-Length. При закрытии запрос отменяется, blob URL освобождается. При повторном открытии содержимое запрашивается заново. Уже законно прочитанное содержимое в открытом окне не может быть отозвано задним числом.

PDF разбирается локальным PDF.js и рисуется на canvas; документы не отправляются внешним viewer-сервисам. HTML из DOCX очищается DOMPurify и помещается в iframe с пустым sandbox и CSP без скриптов/сети. Доступ Mammoth к внешним файлам выключен, активные ссылки удаляются, разрешены только встроенные растровые изображения. Ячейки XLSX и текстовые форматы выводятся как текст React.

## Сборка

Новые зависимости закреплены в `web/package.json` и lock-файле. PDF.js требует Node.js 22.13 или новее; build-stage Docker переведён на `node:22-alpine`. Финальный runtime остаётся nginx.

`npm install` выполняет `web/scripts/copy-pdf-assets.mjs`: CMap, стандартные шрифты, WASM и лицензия PDF.js копируются из установленной зависимости в `web/public/pdfjs/`. Этот каталог генерируется и исключён из Git и Docker build context; внутри build-stage он создаётся через postinstall. Это обеспечивает работу без внешних CDN и одинаковые ресурсы для dev/build. Nginx отдаёт worker `.mjs` с MIME JavaScript; отсутствующие PDF-ресурсы возвращают 404 вместо SPA.
