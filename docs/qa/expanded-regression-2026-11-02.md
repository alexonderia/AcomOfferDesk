## Воспроизведение

На локальном стеке с `EMAIL_ENABLED=false` создать новый набор. Имя выходного файла в контейнере должно быть новым: генератор отказывается перезаписывать существующий файл и не меняет существующих пользователей.

```powershell
docker cp backend/tests/runtime/seed_qa47.py backend:/tmp/seed_qa47.py
docker exec -e PYTHONPATH=/app backend python /tmp/seed_qa47.py --output /tmp/qa47-new.json
docker cp backend:/tmp/qa47-new.json .tmp/qa47-credentials.json
$env:E2E_QA47_CREDENTIALS = "$PWD\.tmp\qa47-credentials.json"
$env:E2E_STRICT_CREDENTIALS = 'true'
node web/node_modules/@playwright/test/cli.js test --config web/playwright.config.ts web/e2e/qa47.regression.spec.ts --workers=1
```

Для повторения полного прогона используется новый набор. Адрес для этого набора фиксирован: `http://localhost:8080`. Не запускать генератор на исходном внешнем стенде как процедуру восстановления данных.

Внешний интерфейс контрагента, реальная доставка SMTP/IMAP, нагрузочная проверка и полный ручной перебор подпунктов исходного документа в этот автоматизированный прогон не входят.
