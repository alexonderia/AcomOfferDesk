Ролевые памятки пользователей AcomOfferDesk
Документ состоит из отдельных памяток по ролям. Каждая памятка рассчитана на конкретного пользователя и содержит только тот функционал, который нужен ему для работы.
Пользователю не нужно изучать все роли. Достаточно открыть раздел со своей ролью.
Памятка пользователя (контрагент)
Вам предоставлен доступ к системе для эффективного взаимодействия компании с поставщиками.
Вы работаете с открытыми заявками на закупку: просматриваете доступные заявки, оставляете коммерческие предложения, общаетесь с ответственными по заявке сотрудниками в чате и отслеживаете статус своих КП.
1. Функционал
Раздел
Что можно делать
Актуальные заявки
Следить за новыми заявками и откликаться на них.
Мои заявки
Следить за заявками, по которым уже отправлено КП.
КП
Просматривать своё КП, прикреплять или удалять файлы, удалять отклик.
Чат
Общаться с ответственным сотрудником по конкретному КП.
Профиль
Обновлять личные данные и данные компании.
Обратная связь
Отправлять предложения и замечания по работе сервиса.

Перейдите по ссылке.
Заполните регистрационные данные.
Подтвердите электронную почту.
Дождитесь проверки данных.
После одобрения получите доступ к системе.
До одобрения доступ может быть ограничен.
Если аккаунт создан нашим сотрудником
После получения логина или с помощью указанной в профиле почты:

Задайте пароль через письмо восстановления.
Войдите в систему стандартным способом.
Ссылки из email не выполняют автоматический вход. 
3. Просмотр заявок
У вас есть два основных режима работы.
Актуальные заявки
Здесь отображаются открытые заявки, доступные для отклика.
Вы можете:
открыть карточку заявки;
посмотреть описание, сроки и файлы;
указать сумму КП (опционально);
нажать «Откликнуться» — будет создано КП, к которому можно приложить файл;
указать сумму КП (опционально).
Если по заявке уже есть активный отклик, система откроет рабочее пространство этого КП.
Мои заявки
Здесь отображаются заявки, по которым вы уже оставили КП.
В таблице могут быть видны:
ID заявки;
описание;
статус;
дата открытия и закрытия;
номер КП;
ответственный сотрудник;
последнее обновление;
уведомления о новых сообщениях.
4. Работа со своим КП
Раздел: Мои заявки → выбрать заявку.
В карточке доступны:
информация о заявке;
прикреплённые файлы заявки;
информация о вашем КП;
статус КП;
файлы КП;
чат по КП.
Вы можете:
прикреплять файлы к КП;
устанавливать или изменять сумму КП;
скачивать файлы;
удалять свои файлы, если действие доступно;
удалить отклик;
писать сообщения в чат, если КП не удалено.
5. Статусы КП
Статус
Что означает
На рассмотрении
КП отправлено и ожидает решения.
Принято
КП выбрано для сделки.
Отказано
КП отклонено.
Удалено
Отклик удалён контрагентом.
Если КП удалено, писать новые сообщения в чат нельзя, но история переписки сохраняется.
6. Чат по КП
Чат привязан к конкретному КП, а не к заявке в целом.
В чате можно:
смотреть историю переписки;
отправлять сообщения;
прикреплять файлы к сообщениям.
Сообщения доступны сотрудникам, которые работают с этим КП.
7. Профиль и данные компании
Раздел: Профиль.
Вы можете посмотреть и изменить:
ФИО;
телефон;
e-mail;
ИНН;
наименование компании;
телефон компании;
e-mail компании;
адрес;
дополнительную информацию.
Изменения применяются после сохранения.
Смена пароля выполняется через «Восстановить доступ» на странице входа.
8. Email-уведомления
Вам на почту могут приходить письма-уведомления о важных событиях:
появилась новая заявка;
изменилась заявка, по которой уже оставлено КП;
изменился статус КП;
появилось событие, требующее входа в систему.
9. Обратная связь
Используйте кнопку «Обратная связь», чтобы отправить замечания, предложения или идеи по улучшению сервиса.
Памятка оператора
Вы создаёте и сопровождает свои заявки на раннем этапе. Ваша задача — корректно заполнить исходные данные, приложить необходимые файлы и поддерживать заявку в актуальном состоянии до передачи в работу ответственному сотруднику.
1. Функционал
Раздел
Что можно делать
Заявки
Создавать заявки и редактировать заявки до назначения ответственного.
Профиль
Просматривать и обновлять свои контактные данные.
Обратная связь
Отправлять предложения и замечания по работе сервиса.
2. Создание заявки
Раздел: Заявки → Создать заявку.
Заполните описание заявки.
Выберите дедлайн сбора КП. Дедлайн не может быть раньше текущего дня.
Укажите «Сумму по ТЗ».
Выберите актуальный нормативный документ. Без него создать заявку нельзя.
Прикрепите минимум один файл заявки, обычно это ТЗ на закупку.
При необходимости включите скрытие от выбранных контрагентов.
При необходимости добавьте дополнительную email-рассылку.
Нажмите «Создать заявку».
После создания заявка появится в списке. 
3. Работа со своими заявками
Раздел: Заявки → выбрать свою заявку.
Оператор может редактировать:
статус своей заявки;
дедлайн;
сумму по ТЗ;
итоговую сумму;
файлы заявки.
После любых изменений нажмите «Сохранить изменения».
После назначения заявки другому ответственному заявка становится недоступной.
4. Важные ограничения
Система не позволит сохранить заявку, если:
нет изменений;
суммы заполнены некорректно;
сумма отрицательная;
при закрытии не указана итоговая сумма;
активная заявка имеет дедлайн раньше текущей даты;
для повторного открытия заявки не указан актуальный дедлайн.
5. Профиль оператора
В профиле можно:
посмотреть логин;
посмотреть ФИО, телефон и e-mail;
изменить данные для связи;
сменить пароль через «Восстановить доступ» на странице входа.
Памятка экономиста
Вы работает со своими заявками и заявками, своих подчиненных. Вы создаёте заявки, анализируете КП, выбираете подходящие предложения и общаетесь с контрагентами в чатах.
1. Функционал
Раздел
Что можно делать
Процесс работы
Смотреть загрузку сотрудников и распределять заявки.
Экономия
Смотреть результаты экономии по закрытым заявкам.
План
Следить за выполнением плана модуля и делегировать его выполнение подчиненным.
Заявки
Просматривать заявки всего подразделения, создавать и вести свои заявки и заявки своих подчиненных.
КП
Просматривать КП по своим заявкам и менять их статус.
Чат
Общаться с контрагентами по КП.
Контрагенты
Просматривать контрагентов, создавать ручные карточки и отправлять приглашения.
Сотрудники
Работать с подчинёнными экономистами, если они есть в иерархии.
Профиль
Обновлять контактные данные и указывать нерабочий период.
Обратная связь
Отправлять предложения и замечания.
2. Дашборд → Процесс работы
Доступна статистика по модулю:
количество сотрудников;
количество заявок в работе;
количество нераспределённых заявок;
диаграмма процесса заявок;
распределение загрузки сотрудников;
дерево подчинённости;
карточки заявок.
В карточках заявок можно назначать ответственных из доступных подчинённых сотрудников. Назначение подтверждается кнопкой «ОК» для отдельной заявки.
Изменения можно сохранить пакетно кнопкой внизу списка.
Система не позволит назначить ответственным сотрудника, который находится в нерабочем периоде.
3. Дашборд → Экономия
Доступна статистика по модулю:
количество закрытых заявок;
заявки с расчётом экономии;
заявки с положительной экономией;
заявки с упущенной экономией;
диаграмма соотношения экономии и упущенной экономии;
списки заявок по категориям.
Списки можно разворачивать и сворачивать для просмотра деталей. Статистику можно отфильтровать по проекту и дате, а также по модулю (если расширен доступ).
4. Дашборд → План
Доступна статистика по модулю:
общий план – совокупные характеристики по всем планам на странице (экономия, выполнение, остаток, число участников);
карточка «Выполнение плана» показывает, какой процент плана уже выполнен и сколько осталось;
карточка «Распределение плана по сотрудникам» показывает, как сумма плана распределена между участниками модуля;
карточка «Заявки, формирующие экономию» показывает, какие заявки вносят вклад в выполнение плана;
в иерархии планов видны узлы с показателями: план узла, распределено, выполнено, не распределено и процент выполнения;
каждый план (если он создан вами или назначен вашему подчиненному) можно декомпозировать (создать подплан), делегировать, редактировать, закрыть план и удалить.
Некоторый функционал может быть ограничен доступами. Статистику можно отфильтровать по дате и по модулю.

сумму по ТЗ;
итоговую сумму;
файлы заявки.

7. Статусы заявки
Статус
Что означает
Открыта
Идёт сбор КП от контрагентов.
На рассмотрении
Сбор КП завершён, идёт анализ предложений.
Закрыта

Отменена

8. Ограничения при сохранении заявки
Система не позволит сохранить заявку, если:
нет изменений;
суммы некорректны или отрицательные;
при закрытии не указана итоговая сумма;
заявка закрывается без принятого КП, но итоговая сумма не совпадает с суммой по ТЗ;
заявка закрывается с принятым КП, но у КП не указана сумма;
заявка закрывается с принятым КП, но итоговая сумма не совпадает с суммой по ТЗ или суммой принятого КП;
для повторного открытия не указан актуальный дедлайн;
активная заявка имеет дедлайн раньше текущей даты.
9. Работа с КП
Раздел: Заявки → выбрать заявку → список КП.
Экономист может:
смотреть КП по своим заявкам;
изучать данные контрагента;
скачивать файлы;
принимать КП;
отклонять КП.
Создание КП вручную
Откройте свою заявку и перейдите к списку КП.
Нажмите «Внести КП вручную».
Выберите существующего контрагента или создайте нового прямо в форме.
При необходимости укажите сумму КП и прикрепите документы.
Нажмите «Создать КП». После создания КП появится в списке по заявке.

10. Чат по КП
Раздел: Заявки → выбрать заявку → выбрать КП → открыть чат.

11. Контрагенты
Раздел: Контрагенты.
Можно:
просматривать список контрагентов и карточки компаний;
создавать ручных контрагентов, если нужно внести КП или добавить компанию без самостоятельной регистрации;
редактировать доступные данные ручных контрагентов;
отправлять приглашения контрагентам по e-mail.
Отправка приглашения
Нажмите «Пригласить» в разделе контрагентов.
Выберите актуальный документ в поле «Презентация-инструкция».
Введите один или несколько e-mail контрагентов.
Проверьте пример письма и нажмите «Отправить».
12. Работа с подчинёнными
Раздел: Сотрудники.
Если у экономиста есть подчинённые в иерархии, он может видеть их карточки и выполнять доступные действия:
изменить статус профиля;
сменить руководителя в рамках доступной иерархии;
установить нерабочий период.
Нельзя управлять сотрудниками вне своей иерархии.

В профиле можно:
посмотреть логин;
изменить ФИО, телефон и e-mail;
установить свой нерабочий период;
Смена пароля выполняется через «Восстановить доступ» на странице входа.

проверить список документов, если пользователи не могут создать заявку из-за отсутствия актуального документа.

в иерархии планов видны узлы с показателями: план узла, распределено, выполнено, не распределено и процент выполнения;
каждый план (если он создан вами или назначен вашему подчиненному) можно декомпозировать (создать подплан), делегировать, редактировать, закрыть план и удалить.
Некоторый функционал может быть ограничен доступами. Статистику можно отфильтровать по дате и по модулю.
5. Создание заявки
Раздел: Заявки → Создать заявку.
Заполните описание заявки.
Выберите дедлайн сбора КП. Дедлайн не может быть раньше текущего дня.
Укажите «Сумму по ТЗ».
Выберите актуальный нормативный документ. Без него создать заявку нельзя.
Прикрепите минимум один файл заявки, обычно это ТЗ на закупку.
При необходимости включите скрытие от выбранных контрагентов.
При необходимости добавьте дополнительную email-рассылку.
Нажмите «Создать заявку».
После создания заявка появится в списке.

8. Ограничения при сохранении заявки
Система не позволит сохранить заявку, если:
нет изменений;
суммы некорректны или отрицательные;
при закрытии не указана итоговая сумма;
заявка закрывается без принятого КП, но итоговая сумма не совпадает с суммой по ТЗ;
заявка закрывается с принятым КП, но у КП не указана сумма;
заявка закрывается с принятым КП, но итоговая сумма не совпадает с суммой по ТЗ или суммой принятого КП;
для повторного открытия не указан актуальный дедлайн;
активная заявка имеет дедлайн раньше текущей даты.

Некоторый функционал может быть ограничен доступами. Статистику можно отфильтровать по дате и по модулю.
5. Создание пользователя
Раздел: Пользователи → Добавить.
Нажмите «Добавить».
Выберите роль:
Контрагент;
Руководитель проекта;
Ведущий экономист;
Экономист;
Администратор;
Служба безопасности;
Оператор.
Для сотрудника заполните:
логин;
e-mail;
ФИО и телефон, если нужно;
руководителя, если требуется.
Для контрагента заполните данные компании.
Нажмите «Создать сотрудника», «Создать контрагента» или «Создать пользователя» — точный текст зависит от выбранной вкладки.
Пароль при создании пользователя в интерфейсе не задаётся. Первый вход сотрудника или ручного контрагента выполняется через «Восстановить доступ» на странице входа по e-mail, указанному в профиле.
6. Просмотр данных пользователя
Раздел: Пользователи → открыть карточку пользователя.
Доступны:
логин;
статус профиля;
ФИО;
телефон;
e-mail;
данные компании у контрагентов.
7. Изменение статуса пользователя
Доступные статусы:
Статус
Что означает
review = на рассмотрении
Пользователь на проверке.
active = активен
Доступ разрешён.
inactive = неактивен
Доступ временно отключён.
blacklist = черный список
Пользователь заблокирован.
После выбора статуса нажмите «Сохранить статус».
8. Изменение роли пользователя
Раздел: Пользователи → нужная вкладка → столбец «Роль».
Смена роли доступна для пользователей, у которых поле «Роль» активно для редактирования.
Доступные варианты ролей определяются правами текущего пользователя и ограничениями системы. Суперадмин может назначать доступные роли приложения, кроме роли суперадмина для новых пользователей.
9. Контрагенты
Раздел: Контрагенты.
Можно:
просматривать список контрагентов и карточки компаний;
создавать ручных контрагентов;
редактировать доступные данные ручных контрагентов;
менять статус доступа, если действие доступно;
отправлять приглашения контрагентам по e-mail.
Отправка приглашения
Нажмите «Пригласить» в разделе контрагентов.
Выберите актуальный документ в поле «Презентация-инструкция».
Введите один или несколько e-mail контрагентов.
Проверьте пример письма и нажмите «Отправить».
10. Нормативные документы
Раздел: Нормативные документы.
Нормативный документ обязателен при создании заявки и используется в приглашениях контрагентам.
Суперадмин может:
добавить новый нормативный документ кнопкой «Добавить документ»;
скачать любой документ из списка;
перевести документ в статус «Актуальный» или «Устаревший»;
оставить актуальными только те документы, которые можно выбирать при создании заявки и отправке приглашений;
проверить список документов, если пользователи не могут создать заявку из-за отсутствия актуального документа.
11. Создание заявки
Раздел: Заявки → Создать заявку.
Заполните описание заявки.
Выберите дедлайн сбора КП. Дедлайн не может быть раньше текущего дня.
Укажите «Сумму по ТЗ».
Выберите актуальный нормативный документ. Без него создать заявку нельзя.
Прикрепите минимум один файл заявки, обычно это ТЗ на закупку.
При необходимости включите скрытие от выбранных контрагентов.
При необходимости добавьте дополнительную email-рассылку.
Нажмите «Создать заявку».
После создания заявка появится в списке. 
12. Изменение заявки
Раздел: Заявки → выбрать заявку.
Суперадмин может изменить:
статус заявки;
ответственного;
дедлайн;
сумму по ТЗ;
итоговую сумму;
файлы заявки.
После изменений нажмите «Сохранить изменения».
13. Работа с КП и чатами
Суперадмин может просматривать закупочный процесс целиком:
смотреть КП;
смотреть данные контрагентов;
скачивать файлы;
менять статус КП, если действие доступно;
смотреть переписку;
писать в чат, если действие доступно для текущего объекта.
Создание КП вручную
Откройте заявку и перейдите к списку КП.
Нажмите «Внести КП вручную».
Выберите существующего контрагента или создайте нового прямо в форме.
При необходимости укажите сумму КП и прикрепите документы.
Нажмите «Создать КП». После создания КП появится в списке по заявке.
14. Профиль суперадмина (недоступен)
Смена пароля выполняется через «Восстановить доступ» на странице входа.
