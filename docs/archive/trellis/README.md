# Локальная история Trellis

10.11.2026 Trellis заменён на версионируемый [AGENTS.md](../../../AGENTS.md) и тематические документы из [каталога](../../README.md).

Локальный файл `2026-11-10-local-context.zip` содержит исходные `.trellis/`, `.agents/` и `.codex/`: спецификации, задачи, журналы, scripts и настройки hooks. Временное `.runtime/` и Python caches исключены.
ZIP проверен на целостность и совпадение SHA-256 каждого исходного файла. Он намеренно игнорируется Git, как раньше игнорировалась большая часть этого контекста; в новом checkout его не будет.

Это архив решений, не исполняемая инструкция. Не распаковывайте его поверх проекта для обычной работы: проектный workflow больше не зависит от Trellis. Пользовательская настройка модели Codex остаётся в пользовательском конфиге и не менялась.
