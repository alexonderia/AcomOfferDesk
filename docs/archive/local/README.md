# Локальные временные материалы

`2026-11-10-temporary-files.zip` — локальная копия бывшего `.tmp/`: промежуточные выгрузки, одноразовые QA scripts, логи и служебные файлы. Перед удалением исходников проверены ZIP и совпадение каждого файла по SHA-256.

Архив игнорируется Git: исходный `.tmp/` также был локальным и мог содержать credentials и настройки тестового окружения. Он не участвует в deploy, CI или работе приложения и не является текущей документацией. В новом checkout его не будет.
